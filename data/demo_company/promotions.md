## Standing Promotions (Year-Round)

### Free Standard Shipping
Orders of **$75 or more** (after any discounts, before tax) qualify for free Standard Shipping automatically. No code required.

### First Order Discount
New customers receive **10 % off** their first order. The discount code is emailed after account creation. Valid for **30 days** from account creation date. Minimum spend: $20. One use per customer.

### Bundle & Save
When two or more Nova-branded products from the same category are purchased together, an automatic **5 % bundle discount** is applied to the lower-priced item. Combinable with Rewards points but not with tier discounts or promo codes.

## How Discounts Stack

Nova Retail applies discounts in the following order of priority:

1. Sale event or promotional code (whichever is greater)
2. Membership tier discount (if no promo code is present)
3. Rewards points redemption
4. Bundle discount
5. Free shipping threshold

Two percentage discounts from the same category (e.g. a sale discount and a promo code) are **never combined** — the greater one applies.

## Promo Code Terms

- Each code specifies its own minimum cart value, eligible categories, and expiry date.
- Codes are **case-sensitive** — copy-paste to avoid errors.
- Most codes are single-use per account.
- Codes cannot be combined with another promo code.
- Codes cannot be applied retroactively to placed orders.
